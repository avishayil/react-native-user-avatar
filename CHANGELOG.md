# Changelog

All notable changes to this project are documented in this file. This project
adheres to [Semantic Versioning](https://semver.org/) and
[Conventional Commits](https://www.conventionalcommits.org/); release notes below
2.0.0 are summarized. Entries are generated by `release-it` on each release.

## Unreleased

### ⚠ BREAKING CHANGES

- `react` and `react-native` are now peer dependencies.
- Removed the `abortcontroller-polyfill` and `node-fetch` runtime dependencies in
  favor of the global `fetch`/`AbortController`.

### Features

- Full TypeScript rewrite with bundled type definitions.
- New `ignoreContentType` prop to support hosts (e.g. S3) that omit `content-type`.
- Initials are capped at three characters.

### Bug Fixes

- `textStyle` is now applied reliably, including after the async render (#117, #98).
- Removed deprecated `defaultProps` usage and the associated console warning (#131, #130).
- Aborted image fetches no longer emit a console warning (#103).
- Corrected the published TypeScript types path (#114, #129, #98).
- Removed the fragile platform-specific header access and the require-cycle warning (#118).
